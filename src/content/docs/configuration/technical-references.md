Product guides explain what a reviewer or administrator can accomplish. They do not duplicate
function signatures, schemas, protocol fields, or implementation architecture.

- Use the [harness developer documentation](https://sangrep.github.io/harness/) for public APIs, CLI
  behavior, examples, and extension points.
- Use the [contracts reference](https://github.com/sangrep/contracts/tree/master/docs) for public
  schemas, compatibility rules, and conformance material.

When either reference is unavailable, treat the technical detail as unavailable. A copied excerpt in
a product guide is not a substitute for its canonical component source.
