Use this documentation to decide whether a guide applies **before** following its steps. Every page
states the relevant platform and version, what may leave the device, known limits, and a safe
recovery action.

No Sangrep Workbench product guide is marked Released yet. That is deliberate: a development build,
preview, screenshot, or passing test does not establish public availability.

## Start with the release boundary

1. Open [How to read guide status](/start/read-guide-status/).
2. Match the page's version and platform to the build you are using.
3. Read the privacy, limitations, and recovery fields before starting a task.
4. If no Released guide matches, stop. Do not use a development guide as a support claim.

## What belongs here

Released guidance covers tasks a reviewer or administrator can actually complete in Sangrep
Workbench. Implementation details, APIs, schemas, and extension contracts remain with their
canonical component references instead of being copied into product guides.

## Current release record

The [release notes index](/releases/) records only accepted product releases. It currently carries
no Sangrep Workbench release entry.
